# Laravel skeleton (placeholder)

This directory contains placeholder files representing the Laravel application scaffold.

Next steps (to be performed locally or by CI runner):
1. Run `composer create-project laravel/laravel .` in this directory to install the real framework.
2. Copy the migration SQL files from `database/migrations/` into `database/migrations` as proper Laravel migration classes (artisan make:migration).
3. Install frontend: `npm install` in `frontend/` and run `npm run dev` for development.

This placeholder is committed to show the intended structure for Phase 0. The full Laravel framework files are not committed here to keep the repo small; installation should be done locally or via a CI job.
